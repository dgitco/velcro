Keeps your network shares mounted.

velcro is a small menu bar app for macOS. When Wi‑Fi drops, your Mac sleeps, or you change networks, it quietly reconnects your SMB and NFS shares.

Install View on GitHub

macOS 13 or later · Apple silicon and Intel · Free and open source

In the menu bar

Shares are grouped by server. Open one in Finder, reconnect it, or remove it. Pause velcro when you want an ejected share to stay ejected.

  • AttachedEvery share is mounted.
  • DetachedSomething dropped. velcro is reconnecting.
  • PausedEjected shares stay ejected.

How it works

  • Reconnects on its ownWhen the network changes, when your Mac wakes, and every minute in between.
  • Never hangs your MacIt reads the mount table instead of touching a share, so a dead server can't freeze Finder or a terminal.
  • Fallback hostsTry the LAN address first, then a Tailscale name, or any other route.
  • No dialogsIt uses the password already in your keychain and writes problems to a log.
  • SMB and NFSSMB is the better fit on a Mac. NFS works for servers that only speak it.

Also in the menu

  • Voice recorder importPlug in a USB recorder and velcro copies its recordings to a folder on your NAS, reads each copy back and compares its size and SHA-256, then clears the recorder and ejects it. If any file doesn't match, nothing is deleted. When the NAS is away, recordings wait on your Mac and move over once it's back.
  • Send to your serverPick a recent screenshot or file and velcro saves it in your NAS inbox, then copies the path your server sees, ready to paste into a terminal over SSH. The clipboard only changes when you pick something.

Command line

Everything the app does is a velcro command, sharing the same settings.

velcro add smb://me@nas.local/home
velcro add smb://me@192.168.1.10/photos nas.tail1234.ts.net
velcro status
velcro pause
velcro import
velcro send screenshot.png

Install

Let your agent do it. Paste this into Claude Code, Codex, or Cursor. It installs velcro, finds the shares you already have mounted, and asks before adding anything.

Set up velcro on this Mac (https://velcro.dgit.co). It keeps SMB and NFS shares mounted, and can also import a USB voice recorder and send files to a NAS inbox.

1. Install it: curl -fsSL https://velcro.dgit.co/install | sh
   If I only want the command line: curl -fsSL https://velcro.dgit.co/install | sh -s -- --cli-only
   velcro goes in ~/.local/bin; use the full path if that isn't on PATH yet.
2. List the shares mounted right now (mount -t smbfs; mount -t nfs) and ask which ones velcro should keep mounted. Add each with: velcro add smb://user@host/share  (spaces as %20). If I reach that server another way too, like a Tailscale name, put it after the address as a fallback host.
3. Ask whether I want either of these, and set up only what I say yes to:
   - Voice recorder: I plug it in, you run velcro recorder add, then velcro set import.dest <a folder on one of the shares>
   - Send to NAS: velcro set send.inbox <a folder on a share>, and velcro set map "<that share's path on this Mac> -> <its path on my server>"
4. Finish with velcro status and tell me what's set up.

Only change things with velcro commands; velcro help lists them. If macOS asks for a share's password, tell me to tick "Remember this password in my keychain".

Or run it yourself. The menu bar app and the velcro command:

curl -fsSL https://velcro.dgit.co/install | sh

Just the command, no app: add -s -- --cli-only after sh. Every download is checked against its published SHA-256 before anything is installed. Read the script.

Questions

Why does macOS say it can't check velcro?

velcro is free and isn't notarized, which takes a paid Apple Developer membership. macOS only checks apps a browser downloaded, so installing with the curl command skips the dialog; the installer checks the download's SHA-256 instead. If you downloaded the zip, open velcro once, click Done, then click Open Anyway in System Settings › Privacy & Security. Or run xattr -dr com.apple.quarantine /Applications/velcro.app.

What will macOS ask me to allow?

Notifications, to tell you when an import or a send is done, and Login Items, to start at login. The first time velcro imports or sends, macOS may ask to let it open files on a removable volume or a network volume. velcro doesn't need Full Disk Access, Accessibility, or Screen Recording.

Does velcro see my passwords?

No. Share passwords stay in your keychain; macOS uses them to mount and velcro never reads them. If there's no saved password, macOS shows its own login window once. velcro keeps no tokens or keys of its own.

What does it do with my clipboard?

It notices when you copy an image or a file and lists the last four in the menu. Copied images are kept in ~/Library/Application Support/velcro/clips until they drop off the list or velcro quits, and anything a password manager marks as private is skipped. velcro only writes to the clipboard when you pick something to send, and never sends anything on its own.

Where does it keep things?

Shares and settings in ~/.config/velcro, the log in ~/Library/Logs/velcro.log, and recordings waiting for the NAS in ~/Library/Application Support/velcro/import-queue.

How do I uninstall it?

Run velcro uninstall, then move velcro.app to the Trash. Delete ~/.config/velcro too if you want your settings gone.
